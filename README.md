# Max Chat

Веб-мессенджер с ограниченным функционалом для отправки и получения сообщений через GREEN-API.

## Возможности

- вход по учётным данным GREEN-API (`idInstance`, `apiTokenInstance`)
- создание нового чата по номеру телефона получателя
- отправка текстовых сообщений
- просмотр ответов получателя в чате

## Стек

- React 19
- TypeScript
- Vite
- React Router
- CSS Modules

## Требования

- Node.js 20 или новее
- npm 10 или новее

## Запуск

Установите зависимости:

```bash
npm install
```

Запустите сервер разработки:

```bash
npm run dev
```

Приложение будет доступно по адресу http://localhost:5173.

## Настройка

Адрес API по умолчанию: `https://api.green-api.com`. Чтобы изменить его, скопируйте `.env.example` в `.env` и укажите своё значение:

```
VITE_GREEN_API_URL=https://api.green-api.com
```

Учётные данные (`idInstance`, `apiTokenInstance`) вводятся на странице входа и хранятся в `localStorage` браузера.

## Сборка

```bash
npm run build
npm run preview
```

Готовая сборка появится в папке `dist`.

## Структура проекта

Проект организован по методологии Feature-Sliced Design.

```
src/
  app/        инициализация приложения, роутинг, глобальные стили
  pages/      страницы: вход и чат
  widgets/    крупные блоки интерфейса: список чатов, окно чата
  features/   действия пользователя: вход, создание чата, отправка сообщения
  entities/   бизнес-сущности: чат, сообщение, сессия
  shared/     переиспользуемые UI-компоненты и утилиты
```

## Использование

1. Откройте страницу и введите `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API.
2. Введите номер телефона получателя в международном формате, например `79001234567`, и нажмите «Создать чат».
3. Напишите сообщение и отправьте его кнопкой или клавишей Enter.
4. Ответ получателя отобразится в окне чата.
